# React 101 Flashcards

A small React + Vite flashcard app for practicing basic programming concepts.

## Features

- Previous/next flashcard navigation
- Show/hide answer state
- Progress bar for current question
- Component-level styling with CSS files

## Run Locally

```bash
npm install
npm run dev
```
### Proejct Idea Link
https://roadmap.sh/projects/flash-cards

## Scripts

- `npm run dev` starts the Vite dev server
- `npm run build` creates a production build
- `npm run lint` runs ESLint
- `npm run preview` previews the production build
